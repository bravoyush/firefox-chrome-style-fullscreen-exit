# Chromium Style Fullscreen Exit

A Firefox web extension that adds a customizable floating Chromium-style fullscreen exit button.

## Features
- Hover near top of screen to display exit overlay
- Switchable button styles: **Glass (macOS translucent style)** & **Solid (Chrome dark style)**
- Configurable button distance, hover detection zone, and hide timeout
- Built for Manifest V3
